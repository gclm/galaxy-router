## 2. 统计模块重构（`docs/design-stats-refactor.md`）

- **目标**：解决三个核心问题——
  - **A. 跨维度数据缺失**：想看「某 API Key 在某模型上的成本」需写 SQL，无法快速定位成本热点
  - **B. 趋势分析缺失**：只有「最近 1 小时」实时数据，无历史对比，无法判断增长/下降
  - **C. 错误分布缺失**：只有笼统错误数，无法区分错误类型，无法定位根因
- **参考**：ccMesh 的 `stats` 模块
- **优先级 / 工作量**：P0，1-1.5 周
- **状态**：待实施
