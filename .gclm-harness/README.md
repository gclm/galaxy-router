# 项目文档体系

## 目录结构

```
.gclm-harness/
├── decisions/          # 决策层 — 确定后基本不变
├── solutions/          # 方案层 — 随迭代演进
├── operations/         # 运维层 — 持续积累
└── reference/          # 参考层 — 静态资料
```

## 文档分类原则

按**生命周期**而非内容形式分类：

| 层级 | 生命周期 | 内容类型 | 变更频率 |
|------|----------|----------|----------|
| `decisions/` | 永久性 | 架构决策、需求愿景、项目约束 | 确定后基本不变 |
| `solutions/` | 演进性 | 功能方案、优化方案、开发计划 | 随迭代更新 |
| `operations/` | 积累性 | SOP 排查、问题记录 | 持续积累 |
| `reference/` | 静态性 | 竞品分析、开发规范 | 很少变更 |

## 文档归属判断

```
这个文档在讲什么？
    │
    ├── "为什么这样" → decisions/
    ├── "怎么做"     → solutions/
    └── "出了问题"   → operations/
```

## 与其他目录的关系

| 目录 | 定位 | 目标读者 |
|------|------|----------|
| `docs/` | 对外文档（使用手册、安装指南） | 用户、贡献者 |
| `.gclm-harness/` | 内部知识库 | 开发者、维护者、AI |
