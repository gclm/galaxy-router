# Startup

每次启动按顺序读取：

1. `must/project-basics.md`
2. `must/pitfalls.md`

需要更多信息时按需读取：
- 开始新功能 → 读 `sop/feature.md`
- 修 bug → 读 `sop/issue.md`
- 重构 → 读 `sop/refactor.md`
- 需求不清 → 读 `sop/brainstorm.md`
- 了解项目 → 读 `overview/project-overview.md`
- 了解架构 → 读 `architecture/ARCHITECTURE.md`
- 查编码规范 → 读 `reference/conventions.md`
- 查开发计划 → 读 `guides/roadmap.md`
